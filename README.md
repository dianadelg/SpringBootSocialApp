# SpringBootSocialApp
A Spring Boot REST API built incrementally to improve backend development, MVC, and database integration.

**Road Map**
Road Map:
_1. Hello World_
Create a Spring Boot project, run a server, return text from an endpoint
_2. REST APIs & MVC_
Controllers, HTTP methods, request/response, JSON
_3. Dependency Injection_
Services, constructors, @Service, @Autowired and Spring beans
_4. Models & DTOs_
Represent users and posts; understand data transfer
_5. CRUD Operations_
Create, read, update and delete users and posts
_6. Database Integration_
Spring Data JPA, repositories, SQL and relationships
_7. Validation & Errors_
Validate requests and handle exceptions
_8. Authentication & Security_
Sign-up, login, password hashing and permissions
_9. Social Features & Testing_
Posts, photos, feeds, tests and application configuration
